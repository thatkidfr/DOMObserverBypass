# DOM Observer Bypass
Simple yet effective bypass for DOM bots inspecting your browser. This is used in monitoring systems, most commonly seen at school or work.

It works by keeping the tab loading continuously, preventing many DOM bots that rely on mutations from detecting anything.

Keep in mind: If the tab stops loading, it is no longer preventing anything

## Usage

*Disclaimer: If you don't have experience with HTML/coding, implementing this is inherently going to be difficult.*

Using this bypass is very simple. 

- Copy the HTML code from bypass.html (Option 1 or 2 both work fine).
- Paste that code into your website

By default, this causes an annoying iframe block to appear. 
Use the code in bypass.html to remove this block.

## Will it Work

If the DOM bot is picking up on keywords/elements inside of a website, then this bypass will most likely work.

e.g. Go to google.com, and in the search bar at the center, type keywords that would most likely trigger the DOM bot. If triggers, then it probably means this bypass will work.
